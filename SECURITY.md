# Security policy

## Reporting a problem
Report security problems privately, not in a public issue.
- Use GitHub private vulnerability reporting on this repository, or
- email email@rishabhsoni.in

Please include the version (see `VERSION`), what you did, and what happened.

## Scope
- The scripts in `scripts/` and the instructions in `.claude/skills/` and `AGENTS.md`.
- Data handling: the separate data folder, saved contact details and photos, and the delete commands.

## Not in scope
- The AI model or provider you choose, and what it logs.
- Your own resume content.
